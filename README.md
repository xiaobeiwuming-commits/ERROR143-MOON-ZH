# ERROR143 月汉化 · 中文补全补丁 0.1.2（测试版）

站内搜索项目名：**ERROR143-MOON-ZH**。

[下载安装包](https://github.com/xiaobeiwuming-commits/ERROR143-MOON-ZH/releases) · [测试报告](QA_REPORT.md)

进入发行版页面，在 **Assets** 中下载 `ERROR143_MOON_ZH_v0.1.2.zip`。`Source code` 是 GitHub 自动生成的项目文件压缩包，玩家请下载上述安装包 ZIP。

适用于 Windows 10 / 11 的 ERROR143 Steam 版，游戏版本 3、Steam Build 25396435。保留游戏已有中文翻译，补充遗漏的界面、剧情文本和隐藏番外。其他玩家可以使用同一安装器，它会自动寻找各自的 Steam 游戏目录。

本版支持本体、Day 5、Day 6、Day 7、Day 8。**Night 7 尚未包含**：制作环境没有找到 `day_seventwo_dlc.rpa`，因此这版不能标为“全 DLC 完整汉化”。其他游戏版本和其他汉化模组的兼容性尚未验证。

## 安装

1. 自行安装 ERROR143 及希望游玩的 DLC，然后关闭游戏。
2. 解压分享包，双击 `ERROR143_Chinese_Patch_Setup.exe`。
3. 确认游戏目录。应选择包含 `Error143.exe` 和 `game` 文件夹的目录；自动识别不正确时点击“浏览”。
4. 点击“安装 / 更新”，等待版本校验和安装完成。校验会读取本体资源，耗时随硬盘速度变化。
5. 启动游戏，在设置中选择“中文”。

从 0.1.1 更新时，关闭游戏后运行 0.1.2 安装器，选择同一游戏目录并点击“安装 / 更新”即可，无需先卸载。原有备份继续保留。

只有手动点击设置中的“中文”按钮后，右下角才会显示 4 秒提示：“此汉化包制作于26.10.1，木灵和八一。”。启动游戏、读取存档和返回主菜单不会触发提示；提示自动消失，切换到其他语言或离开当前交互时会收起。0.1.2 已移除 0.1.1 的语言初始化提示回调。

安装器内置补丁，不需要 Python、Ren'Py SDK 或本项目工作目录。DLC 可以缺省；已安装的本体和受支持 DLC 必须与本版记录的资源哈希一致。版本不匹配时会停止安装。

## 卸载与恢复

关闭游戏，重新运行同一安装器，选择原游戏目录，点击“卸载 / 恢复”。安装前已有的同名文件会从自动备份中恢复；安装后由本补丁新增的文件会移除。备份保留在游戏目录的 `.error143_zhpatch_backup` 文件夹，安装记录为 `.error143_zhpatch_state.json`。保留这两项可供恢复。

如果补丁文件或备份被手动编辑，安装器会停止覆盖或恢复，以免丢失修改。请先另存自己的修改。安装器不编辑存档。

## 本版内容与验证

- 334 项新增或补全的短文本，涵盖界面、弹窗、成就、时间提示和存档日期。
- 68 处剧情文本修正，保留原有角色、语音、分支与跳转。
- 11 篇隐藏番外的中文文本。
- 两种成就图片横幅及三页新手教程的中文显示。
- 使用实际游戏引擎验证补丁载入、变量替换、文字标签、中英文切换和四个 DLC 的入口标签。
- 检查主菜单、设置、成就、画廊、教程和示例文字画面；安装器通过 26 项安装与恢复断言，并在隔离的同版本游戏资源上完成安装、引擎启动与卸载验证。
- 10 个本机旧存档副本各读取 3 次，30 次均成功恢复游戏且没有提示；验证了 0.1.1 提示显示时保存的存档和实际返回主菜单流程。原存档哈希未改变。

当前测试未重现玩家报告的偶发无报错读档失败；这些通过结果不能保证所有旧存档都已兼容。

这版尚未逐一通关所有剧情分支，也没有人工逐句重校游戏原有全部中文译文。人名、网站品牌、音乐名称、键盘按键和需要按原文输入的解谜密码保留原文；部分装饰图案中的文字尚未逐张检查。发现漏译时，请记录所在章节、原文及当前中文，便于后续补充。
